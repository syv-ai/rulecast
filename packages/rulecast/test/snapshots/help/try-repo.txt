rulecast try-repo <path|url> [RULE_ID] [--ref REV] [run flags]

Run a rule repo against your project without configuring it

  --ref REV  The revision of a URL repo (default HEAD)

Exit codes:
  0  Every rule ran; no new error-severity findings (warnings and pre-existing findings allowed)
  1  Every rule ran; at least one new error-severity finding
  2  rulecast could not run: usage, the rule repo cannot be fetched or has no manifest, a config file that does not load, git, or an internal error
  3  Incomplete: a rule failed to compile, a detector failed or timed out. Findings that were produced are still reported. Wins over 1
The JSON and SARIF output is documented in agents/reference/output.md.
