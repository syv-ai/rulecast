# Which sources can be read online, 2026-10-13

A background agent checked each source in `docs/references.md` for what can legitimately be read online: hosted by the author, the publisher, a standards body or an official project site. It distilled nothing. "200" means the URL answered when fetched.

**Limits.** O'Reilly answered 403 to every automated request, so its free previews (sources 2, 4, 11, 18, 20, 22) are unverified. The ACM Digital Library (6) also answered 403. Crossref lists the official PDF there, and ACM opened its 1951–2000 archive in 2022.
