`agents/CONVENTIONS.md`: a new agent doc for working out a project's conventions with the developer before any rule is drafted. The agent reads the code with subagents that only observe, then interviews the developer one question at a time, recommending from rulecast's lens catalog (`agents/lenses/`, generated by `pnpm lenses`), and the developer reviews the result on one page. `init`'s drafting prompt and `SETUP.md` now start there; `DRAFT-RULES.md` stops when a doc states no conventions.
