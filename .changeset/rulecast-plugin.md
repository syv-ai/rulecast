A Claude Code plugin with one skill, `/rulecast:add-rule`. Install it with `/plugin install rulecast --marketplace syv-ai/rulecast`. With no argument it turns the mistake the session just showed into a rule; with one, the convention you name. The agent states the convention back, writes it into your docs if it isn't there, drafts and measures the rule as `agents/DRAFT-RULES.md` describes, and asks you before keeping anything. The plugin's version follows the CLI's.
